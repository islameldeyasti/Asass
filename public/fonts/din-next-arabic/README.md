# DIN Next Arabic — font files

Place licensed **DIN Next Arabic** `.woff2` files in this folder:

| File | Weight |
|------|--------|
| `DINNextArabic-Light.woff2` | 300 |
| `DINNextArabic-Regular.woff2` | 400 |
| `DINNextArabic-Medium.woff2` | 500 |
| `DINNextArabic-Bold.woff2` | 700 |

`@font-face` rules are already declared in `Frontend/app/fonts-arabic.css`.

Until these files exist, the site uses:

`"DIN Next Arabic", "IBM Plex Sans Arabic", "Noto Sans Arabic", sans-serif`

Do **not** commit unlicensed font binaries.
